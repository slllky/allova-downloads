# Allova downloads

Official Windows portable downloads for the Allova fan game.

Play the browser game at [armageddonallova.win](https://armageddonallova.win).
Download builds from this repository's Releases page and read each release's test notes.

Windows packages include the game, artwork, music, and runtime for offline single-player play. Phone sign-in, cloud saves, friends, trades, and online battles need internet. Desktop and browser saves are separate; use the existing save export/import tools or explicitly load a cloud adventure.

Portable builds are unsigned. Do not disable Windows security protections. Each release includes a SHA-256 checksum and version provenance.

The source files in this repository are only release verification and packaging infrastructure. They do not include private backend configuration or player data. Third-party game artwork and music remain owned by their respective creators; see the game's existing credits. Electron/Chromium license notices are included in each package.
